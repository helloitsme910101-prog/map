# KosovoMap — Step 1 (MVP)

Native iPhone app. Swift + SwiftUI, MapLibre + OpenStreetMap, SwiftData, CoreLocation. No account, no backend.

**Requires:** Mac with Xcode 26 or newer, iOS 17+ device. (On Xcode 16, delete the `#available(iOS 26.0, *)` branch in `Components/GlassSurface.swift`.)

## What Step 1 includes

1. Premium map screen (floating search, Layers, My Location, floating tab bar, bottom sheets)
2. Kosovo map (OpenFreeMap styles built from OpenStreetMap; camera is kept around Kosovo)
3. GPS with Apple-style location dot, follow and heading modes, permission handling
4. Search: saved places → built-in Kosovo towns (works offline) → online OSM results (Photon)
5. Save This Place: name, category, photo, notes, date, custom markers, edit and delete
6. Local storage with SwiftData (CloudKit disabled)
7. Online / Offline / Auto architecture with a live status pill
8. Light, Dark and System appearance, with matching dark map styles
9. Haptics and subtle spring animations

Not in Step 1 (arrive next): offline Kosovo download, location history, background tracking, daily routes, heatmap.
The History tab, Tracking rows and Download rows are labelled "Step 2" on purpose.

## Set up (option A: XcodeGen, about 2 minutes)

```bash
brew install xcodegen
cd KosovoMap          # the folder containing project.yml
xcodegen generate
open KosovoMap.xcodeproj
```

The MapLibre package and Info.plist keys are configured by `project.yml`.

## Set up (option B: manual Xcode project)

1. Xcode → File → New → Project → iOS → App. Name `KosovoMap`, Interface **SwiftUI**, Storage **None**, Language Swift.
2. Delete the generated `KosovoMapApp.swift` and `ContentView.swift`.
3. Drag the inner `KosovoMap/` source folder (App, Models, Managers, Services, Components, Views, Resources) into the project. Tick "Create groups" and add to the KosovoMap target.
4. Target → General → Minimum Deployments → **iOS 17.0**. Supported destination: iPhone.
5. File → Add Package Dependencies → `https://github.com/maplibre/maplibre-gl-native-distribution` → Up to Next Major from `6.0.0` → add product **MapLibre** to the KosovoMap target.
6. Target → Build Settings → Swift Language Version → **Swift 5**.
7. Target → Info → add **Privacy - Location When In Use Usage Description** (`NSLocationWhenInUseUsageDescription`):
   `KosovoMap shows where you are on the map. Your location stays on this iPhone.`

## Info.plist permissions (Step 1)

| Key | Value |
| --- | --- |
| `NSLocationWhenInUseUsageDescription` | KosovoMap shows where you are on the map. Your location stays on this iPhone. |

Photos use the system `PhotosPicker`, which needs no permission. Step 2 adds `NSLocationAlwaysAndWhenInUseUsageDescription` and the Location background mode.

## Run on a physical iPhone

1. On the iPhone: Settings → Privacy & Security → **Developer Mode** → On, then restart.
2. Connect with a cable and tap **Trust This Computer**.
3. Xcode → target KosovoMap → Signing & Capabilities → tick **Automatically manage signing** → choose your Team (a free Apple ID works; the install expires after 7 days).
4. Change the Bundle Identifier to something unique, e.g. `com.yourname.KosovoMap`.
5. Pick your iPhone in the device menu → **Run** (⌘R).
6. If iOS blocks the app: Settings → General → VPN & Device Management → trust your developer profile.
7. Allow location when asked. Tap the location button to follow you; tap again for heading.

Simulator tip: Features → Location → Custom Location, e.g. 42.6629, 21.1655.

## Honest notes

- **Not compiled yet.** This was written without access to Xcode. Expect to fix a small compile error or two on first build. Send me the exact error text and I'll fix it.
- **Offline mode is partial in Step 1.** It stops online search and shows the status, but MapLibre can still fetch tiles when a connection exists. True offline (a local Kosovo tile file plus offline search) is Step 2.
- **Privacy.** Saved places, photos and settings never leave the phone. While online, map tiles come from OpenFreeMap and search text goes to Photon (komoot). Neither receives your saved places or history.
- **Public services.** OpenFreeMap and Photon are free public services with no uptime guarantee. For an App Store release, self-host or switch to a paid provider.
- **Search coverage.** Offline search covers saved places and about 30 built-in towns (approximate centres). Streets and villages need Step 2.
- **3D buildings.** Toggles a building layer and tilts the camera. It depends on the `openmaptiles` source in the chosen style.
- **Traffic** is not available with OpenStreetMap data.

## No Mac? Build with GitHub Actions (free)

1. Create a GitHub repository and upload the contents of this folder (`project.yml` must be at the repo root).
2. Make sure `.github/workflows/build-ipa.yml` is included.
3. Repo → Actions → "Build KosovoMap IPA" → Run workflow.
4. When it finishes, download the `KosovoMap-ipa` artifact. If it fails, download `build-log` and send me the error lines.
5. On Windows, install Sideloadly (plus iTunes and iCloud from apple.com), connect the iPhone, drag in `KosovoMap.ipa`, sign in with a free Apple ID, and press Start.
6. On the iPhone: Settings → Privacy & Security → Developer Mode → On; then Settings → General → VPN & Device Management → trust your Apple ID. Free signing expires after 7 days; just re-sideload.
